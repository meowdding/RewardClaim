## Features

- Browse reward options.
- Skip the ad automatically if skippable.
- Claim with/without confirmation.
- Configure **Ad Skip** and **No Confirmation** in OneConfig.

OneConfig is optional; the reward screen works without it, but it's settings are only available when OneConfig is installed.

## Installation

Recommended Oneclient or at least Oneconfig, requires the Ornithe libraries.

## Building

Build the mod with Java 25:

```sh
./gradlew build
```
